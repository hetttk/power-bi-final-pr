# Power BI Sales Analytics Project

## Overview

This project focuses on building an end-to-end Power BI solution using Power Query, Data Modeling, and DAX. The project includes data cleaning, relationship building, calculated columns, measures, and time intelligence analysis for Sales and Returns data.

## Features

* Data cleaning and transformation using Power Query
* Star Schema data modeling
* Relationships between fact and dimension tables
* Calculated columns and DAX measures
* Time intelligence calculations
* Matrix-based sales analysis
* KPI calculations for sales, profit, and returns

## DAX Implemented

* Total Sales
* Total Profit
* Return Rate
* Average Sales
* Year-over-Year Growth
* Running Totals
* Filter Context functions (CALCULATE, FILTER, ALL)

## Analysis

* Sales by Region
* Product Category performance
* Customer Segment analysis
* Monthly & Yearly trends
* Returns analysis

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Modeling

## Deliverables

* `.pbix` Power BI file
* Data model with relationships
* DAX calculations and measures
* Matrix-based analytical reports

## Conclusion

This project demonstrates practical Business Intelligence concepts including ETL, data modeling, DAX calculations, and analytical reporting using Power BI.
